# HTML & CSS with AI — Course Proposal

A complete proposal for an introductory web development course that teaches HTML and CSS while using artificial intelligence as a learning and development tool.

**Live site:** https://gleimbek.github.io/HTML-CSSwhitAI/

## What's included

- **Ten modules**, each with explanations, examples and exercises:
  1. Getting Started with HTML
  2. HTML Fundamentals
  3. Getting Started with CSS
  4. CSS Layout
  5. Typography & Styling
  6. Links & Navigation
  7. Images & Media
  8. Lists & Tables
  9. Responsive Design
  10. Web Forms
- **Syllabus** for a 16-week, 3-credit course
- **Student guide** and **instructor guide**
- **Final project** description
- **Resources** page
- Diagrams for the box model, CSS rule anatomy, the DOM tree, form structure, responsive breakpoints and the typography scale

## Built with

HTML, CSS and vanilla JavaScript, no build step.
