STUDENT GUIDE

Learn HTML & CSS with AI

A practical guide to learning web development, using AI tools, writing your own code, and building real webpages.

01 — START HERE

Welcome to the Course

This course introduces you to modern web development through HTML, CSS, responsive design, accessibility, and AI-assisted learning.

You do not need previous professional web development experience. The course is designed to move from fundamental concepts to increasingly complex projects.

Your goal

By the end of the course, you should be able to create, explain, test, improve, and publish a responsive webpage using HTML and CSS.

02 — HOW TO LEARN

The Learning Cycle

1. Learn

Read the lesson and understand the concept before beginning the activity.

2. Ask

Use AI to ask questions when you need another explanation or example.

3. Code

Write and modify HTML and CSS in your development environment.

4. Test

Open your webpage in the browser and verify what actually happens.

03 — USING AI

AI Is Part of the Learning Process

In this course, AI may be used as a learning and development assistant. You will learn how to communicate with AI effectively and how to evaluate its responses.

1. ASK

Ask a specific question.

2. UNDERSTAND

Read the explanation carefully.

3. APPLY

Use the concept in your own project.

4. TEST

Check the code in the browser.

5. VERIFY

Confirm important information using reliable sources.

04 — AI PROMPTS

Examples of Useful Prompts

EXPLAIN

Explain the difference between an HTML element and an HTML attribute using a simple example.

DEBUG

Help me identify the possible problem in this HTML code. Explain the problem before suggesting a correction.

COMPARE

Compare these two CSS approaches and explain when each approach would be useful.

PRACTICE

Give me a short HTML practice problem. Do not give me the solution until I attempt it.

05 — VERIFYING AI

Don't Assume AI Is Correct

AI systems can generate incorrect, outdated, or inappropriate code. Learning to evaluate AI output is therefore part of the course.

  • Read the generated code instead of immediately copying it.
  • Test the code in your browser.
  • Check whether the solution actually addresses the problem.
  • Ask AI to explain unfamiliar code.
  • Consult reliable documentation when necessary.
  • Make sure you understand the final code.
06 — CANVAS

How Each Module Works

1.Overview

3. AI Exploration

4. Coding Lab

6. Quiz

07 — YOUR RESPONSIBILITY

What You Are Expected to Do

  • Complete the assigned learning activities.
  • Write and test code regularly.
  • Use AI to improve your understanding and development skills.
  • Evaluate AI-generated information and code.
  • Ask questions when you do not understand something.
  • Be able to explain the HTML and CSS included in your submitted work.
  • Follow the course's AI-use and academic integrity expectations.
