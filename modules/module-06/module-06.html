MODULE 06

Links & Navigation

Learn how to connect multiple HTML pages with hyperlinks and build a working, accessible site navigation.

MODULE CONTENT

Connecting Pages Together

A website is more than a single page — it is a set of pages connected through links. This module focuses on building working navigation between multiple HTML documents.

Students will practice absolute and relative paths, external links, and accessible navigation markup.

HYPERLINKS

The Anchor Element

Every link on the web is built with the <a> element and its href attribute.

index.html HTML 
About
MDN
Jump to Contact

A relative path (about.html) points to a file inside the same project. An absolute URL points to a page on another domain entirely.

NAVIGATION

Building a Nav Bar

Grouping links inside a <nav> element tells both browsers and assistive technology that this is a navigation region of the page.

index.html HTML 

    Home
    About
    Contact
style.css CSS 
nav a:hover {
    color: #d4af37;
    text-decoration: underline;
}
AI EXPLORATION

Use AI to Debug a Broken Link

AI
EXPLORATION 01

Diagnose a broken relative path

Try this prompt

My link <a href="images/photo.png"> is not working from a page inside a subfolder. List the most common reasons a relative path breaks. Do not just tell me the fix.

Verify

  • Check the actual folder structure of the project.
  • Trace the path manually, one folder at a time.
  • Confirm the fix in the browser before moving on.
