MODULE CONTENT

Adding Images and Media

Images and media make webpages more engaging, but they also introduce responsibilities: accessibility, file size, and layout stability.

This module covers the <img> element, responsive image sizing, and basic video and audio embedding.

IMAGES

The Image Element

Every image needs a src and an alt attribute. The alt text is read aloud by screen readers and shown if the image fails to load.

index.html HTML
style.css CSS 
img {
    max-width: 100%;
    height: auto;
}

Setting max-width: 100% keeps images from overflowing their container on smaller screens.

AI EXPLORATION

Use AI to Draft Alt Text

AI
EXPLORATION 01

Draft and refine alt text

Try this prompt

I am describing a photo of a laptop showing HTML code on a wooden desk, for a course homepage. Suggest two alt text options: one short, one more descriptive. Explain when each length is appropriate.

Verify

  • Read both options aloud and check they make sense without seeing the image.
  • Confirm the alt text does not just repeat the filename.
  • Pick the version that fits the image's purpose on the page.
ASSIGNMENT

Build a Media Gallery Page

1 Add at least four images with meaningful alt text.
2 Use CSS to keep all images responsive (no overflow).
3 Embed at least one video or audio element with fallback text.
4 Use loading="lazy" on below-the-fold images.
5 Organize the gallery using Flexbox from Module 04.
6 Document one AI-assisted alt text drafting session.
AI REVIEW

Use AI to audit your accessibility

AI
REVIEW ACTIVITY

Ask AI to audit, not rewrite

Here is the HTML for my media gallery. Review my alt text for each image and flag any that are missing, vague, or just repeat the filename. Do not rewrite my HTML.

Your goal

Be able to explain why each piece of alt text you kept is actually useful to someone using a screen reader.
