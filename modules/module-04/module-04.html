MODULE CONTENT

Organizing Content with CSS

CSS layout techniques allow developers to control how elements are arranged within a webpage.

In this module, students begin working with the box model, display properties, Flexbox, alignment, spacing, and basic responsive layout concepts.

CSS LAYOUT

The Box Model

Every HTML element can be understood as a box with content, padding, border, and margin.

style.css CSS 
.card {
    width: 300px;
    padding: 20px;
    border: 1px solid #ccc;
    margin: 20px;
}
FLEXBOX

Creating Flexible Layouts

Flexbox provides a practical way to arrange elements along a row or column and control alignment and distribution.

style.css CSS 
.navigation {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
}
AI EXPLORATION

Use AI to Investigate Layout Problems

AI can help students reason about layout problems, but the browser remains the final environment for testing CSS behavior.

AI
EXPLORATION 01

Diagnose a layout problem

Try this prompt

Explain three common reasons why items inside a flex container might not align as expected. Do not rewrite my code.

Verify

  • Test the explanation in a browser.
  • Compare the result with CSS documentation.
  • Explain the final solution yourself.
ASSIGNMENT

Build a Responsive Card Layout

Create a webpage containing multiple content cards and use CSS layout techniques to organize them.

1 Create at least three content cards.
2 Use an external stylesheet.
3 Apply the CSS box model.
4 Use Flexbox for layout.
5 Test the layout at different viewport widths.
6 Document an AI-assisted debugging or learning activity.
AI REVIEW

Use AI to review your layout

After finishing your card layout, use AI to check your own understanding rather than to add or change code.

AI
REVIEW ACTIVITY

Ask AI to teach, not replace

I am learning CSS layout. Here is the Flexbox CSS I wrote for my card layout. Explain what each property controls and identify anything that might break on a narrower screen. Do not rewrite the CSS for me.

Your goal

Be able to explain why your layout behaves the way it does at different screen widths — without relying on the AI response.
