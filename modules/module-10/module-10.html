VALIDATION & STYLING

Guiding the User

style.css CSS 
input:focus {
    outline: 2px solid #d4af37;
    outline-offset: 2px;
}

input:invalid {
    border-color: #c0392b;
}

The required attribute triggers built-in browser validation. Visible focus states are essential for keyboard users.

EXPLORATION 01

Choose the right input type

Try this prompt

I need a form field for a phone number, a birthdate, and a preferred contact method. Suggest the most appropriate HTML input type for each and explain why. Do not write the full form for me.

Verify

  • Test each suggested input type in the browser.
  • Confirm the on-screen keyboard changes correctly on mobile.
  • Check that each choice actually fits the data being collected.
