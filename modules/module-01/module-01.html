OVERVIEW

Welcome to HTML

HTML is the language used to structure the content of webpages. In this module, you will begin by learning how an HTML document is organized and how browsers interpret that structure.

You will create your first HTML document using a text editor and preview it in a web browser. The objective is not simply to memorize tags, but to understand the relationship between HTML code and the content displayed by the browser.

READING

1. Understanding an HTML Document

An HTML document is a text document that contains HTML code. The code identifies different types of content and establishes relationships between elements.

A basic HTML document contains an html element with head and body sections.

index.html HTML 
<!DOCTYPE html>

<html lang="en">

    <head>
        <title>My First Webpage</title>
    </head>

    <body>

        <h1>Welcome to My Website</h1>

        <p>
            This is my first webpage.
        </p>

    </body>

</html>

The document structure

The head section contains information about the document that is not normally displayed as the main page content. For example, the title element specifies the title associated with the browser tab.

The body section contains the content that appears in the main browser window, including headings and paragraphs.

HTML FUNDAMENTALS

2. HTML Elements and Nesting

HTML elements identify different types of content. Many elements use an opening tag, content, and a closing tag.

Opening tag <p>
Content Hello world
Closing tag </p>

Elements can also be nested. When one element is placed inside another element, the inner element is a child of the outer element.

Nested elements HTML 
<body>

    <h1>My Website</h1>

    <p>
        Welcome to my webpage.
    </p>

</body>
Remember

Indentation does not change how HTML is interpreted by the browser, but it makes nesting relationships much easier for people to understand.

HTML CONTENT

3. Adding Text to a Webpage

HTML provides elements for organizing text. Headings communicate the structure of the content, while paragraphs represent blocks of text.

<h1>

Main heading

Represents the highest-level heading on the page.

<p>

Paragraph

Represents a paragraph of text.

Text example HTML 
<h1>Learning HTML</h1>

<p>
    HTML provides the structure
    of a webpage.
</p>
AI EXPLORATION

Learn with AI — Don't just copy

In this course, AI is introduced as a learning support tool. The objective is to use AI to improve understanding, ask better questions, and examine code rather than simply copying generated answers.

AI
EXPLORATION 01

Ask AI to explain HTML

Try this prompt

Explain the basic structure of an HTML document. Describe the purpose of the html, head, and body elements. Do not write code.

Then evaluate the response

  • Does the explanation correctly describe the role of each section?
  • Can you explain the concept without looking at the AI response?
  • What information would you verify using your course materials or reliable documentation?
Verify before you trust

AI-generated explanations can contain errors. Use your course materials and reliable technical documentation to verify important information.
