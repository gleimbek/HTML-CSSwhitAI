MODULE CONTENT

From Structure to Presentation

HTML defines the structure and meaning of webpage content. CSS controls how that content is presented to users.

In this module, students begin working with CSS rules, selectors, properties, values, colors, typography, spacing, borders, and backgrounds.

CSS
Key Idea

HTML describes what content is. CSS describes how that content looks.

CSS FUNDAMENTALS

The CSS Rule

A CSS rule connects a selector with one or more declarations that define how matching elements should be presented.

style.css CSS 
h1 {
    color: #d4af37;
    font-size: 2.5rem;
}
Selector h1
Property color
Value #d4af37

AI EXPLORATION

Explore CSS with AI

Use AI to investigate CSS concepts without giving up responsibility for understanding and testing the resulting code.

AI
EXPLORATION 01

Ask AI to explain a CSS rule

Try this prompt

Explain what a CSS selector, property, and value are. Use one simple example and explain each part. Do not provide additional code.

Evaluate the response

  • Does the explanation correctly identify each part of the rule?
  • Can you explain the rule yourself?
  • Can you verify the explanation using reliable documentation?
Verify before you trust

Test AI-generated CSS in your browser and compare explanations with reliable technical documentation.

AI REVIEW

Use AI to review your stylesheet

After finishing your stylesheet, use AI to check your own understanding rather than to add or change rules.

AI
REVIEW ACTIVITY

Ask AI to teach, not replace

I am learning CSS. Here is the stylesheet I wrote for my profile page. Explain what each rule does and identify any selectors or properties I should study further. Do not rewrite the CSS for me.

Your goal

Be able to explain, for every rule in your stylesheet, which element it targets and why — without relying on the AI response.
