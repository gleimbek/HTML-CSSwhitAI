MODULE 08

Lists & Tables

Learn to structure content with lists and semantic tables — and why tables should never be used for layout.

HTML Core Skill

AI Learning Support
MODULE CONTENT

Organizing Structured Information

Lists and tables give HTML a way to represent structured information — steps, options, and tabular data — in a way that is both visually clear and machine-readable.

This module also addresses a common mistake: using tables for page layout instead of for actual tabular data.

AI EXPLORATION

Use AI to Structure Messy Data

AI
EXPLORATION 01

Convert raw data into a table

Try this prompt

Here is a list of three course modules with their week numbers, written as plain sentences. Convert it into a semantic HTML table with a and . Explain why you grouped the columns the way you did.

Verify

  • Check that the table reads correctly with a screen reader outline.
  • Confirm the table would still make sense without any CSS.
  • Verify no data was dropped or reordered incorrectly.
