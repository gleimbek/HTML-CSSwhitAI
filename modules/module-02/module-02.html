MODULE CONTENT

From Basic Markup to Meaningful Structure

HTML provides the structure and meaning of a web page. In this module, students move beyond individual tags and begin creating complete documents with an organized and meaningful structure.

Students work with document structure, headings, paragraphs, links, images, lists, tables, forms, attributes, and semantic HTML. The emphasis is on understanding how and why elements are used rather than memorizing isolated syntax.

AI is introduced as an active learning and development assistant. Students can ask AI to explain concepts, generate small examples, compare approaches, identify potential errors, and suggest improvements. Students must test and understand the resulting code.

LEARNING OBJECTIVES

By the end of this module, students will be able to:

1

Construct HTML documents

Create properly structured HTML documents using the essential elements of an HTML page.

2

Use elements and attributes

Select appropriate HTML elements and use attributes to provide additional information or functionality.

3

Organize content semantically

Use semantic HTML elements to communicate the purpose and organization of page content.

4

Build practical page structures

Combine HTML elements to create structured pages containing text, links, images, lists, tables, and forms.

5

Apply basic accessibility practices

Use appropriate HTML structure and attributes to improve the accessibility and clarity of web content.

6

Use AI to explore HTML

Develop prompts that use AI for explanations, examples, debugging, comparison, and experimentation.

7

Evaluate AI-generated code

Test, review, modify, and explain AI-assisted HTML before incorporating it into a project.

AI EXPLORATION

Learning HTML with AI

Students will practice a repeatable workflow for using AI while developing HTML skills.

1

Ask

Ask AI to explain an HTML concept or piece of syntax.

2

Explore

Request small examples and compare different ways of solving the same problem.

3

Test

Run the HTML in a browser and verify that the result behaves as expected.

4

Review

Examine the AI-generated code and compare it with the concepts introduced in the module.

5

Explain

Explain the purpose of the code and the reasoning behind the final implementation.

CODING PRACTICE

Build an HTML Profile Page

Students will create a small multi-section profile page using HTML only. The page should demonstrate document structure, headings, paragraphs, links, images, lists, and semantic sections.

Profile page HTML 
<main>

    <section>
        <h1>My Web Profile</h1>
        <p>Welcome to my page.</p>
    </section>

    <section>
        <h2>About Me</h2>
        <p>I am learning web development.</p>
    </section>

    <section>
        <h2>My Interests</h2>

        <ul>
            <li>Web Development</li>
            <li>Technology</li>
            <li>Design</li>
        </ul>
    </section>

</main>
AI REVIEW

Use AI to review your profile page

After building your profile page, use AI to check your own understanding rather than to add or change code.

AI
REVIEW ACTIVITY

Ask AI to teach, not replace

I am learning HTML. Here is the profile page I built. Explain what each section and element does, and point out any semantic elements I could have used instead. Do not rewrite the code for me.

Your goal

Be able to explain, in your own words, why each element in your page was the right choice — without relying on the AI response.

ASSIGNMENT

Semantic Web Page

Create a complete HTML page for a fictional organization, personal portfolio, product, or small business.

The page should demonstrate meaningful HTML structure rather than relying on generic elements for every part of the document.

1 Use a valid HTML document structure.
2 Include multiple heading levels appropriately.
3 Include links and at least one image.
4 Include an ordered or unordered list.
5 Use semantic structural elements.
6 Use AI for at least one learning or debugging activity and document how it was used.
