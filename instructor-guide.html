INSTRUCTOR GUIDE

Teaching HTML & CSS with AI

A teaching framework for delivering HTML and CSS through hands-on development and responsible, transparent use of AI tools.

01 — COURSE VISION

Teaching HTML & CSS with AI

This course teaches foundational web development skills while integrating artificial intelligence into the learning process.

Students learn HTML and CSS by writing, examining, testing, debugging, and improving code. AI tools are introduced as learning and development assistants that can explain concepts, provide examples, identify potential errors, suggest alternatives, and support problem-solving.

Core principle

Students should understand the code they use. AI can accelerate learning and development, but it does not replace the student's responsibility to understand, test, evaluate, and explain the final result.

02 — INSTRUCTOR ROLE

Instructor Responsibilities

1. Teach the fundamentals

Establish strong HTML and CSS foundations before students depend on AI-generated solutions.

2. Model AI use

Demonstrate effective prompts, code review, verification, debugging, and responsible AI use.

3. Evaluate understanding

Assess whether students understand the concepts and decisions represented in their work.

4. Encourage experimentation

Allow students to compare approaches, test solutions, and learn from mistakes.

03 — MODULE DESIGN

Recommended Module Pattern

Each Canvas module follows the same instructional sequence so students know what to expect.

1. Overview

Introduce the purpose, relevance, and learning outcomes of the topic.

2. Reading

Present the technical concepts, terminology, examples, and code.

3. AI Exploration

Students use AI to explore, question, compare, explain, or investigate the topic.

4. Coding Lab

Students write and test code through guided hands-on activities.

5. Assignment

Students apply the concepts in an individual development task.

6. Quiz

Check conceptual understanding and terminology.

7. Reflection

Students explain what they learned, what they changed, and how AI helped.

04 — AI PEDAGOGY

AI as a Learning Partner

AI activities should be connected directly to the HTML or CSS concept being taught.

1. ASK

Ask AI a focused technical question.

2. EXAMINE

Read and analyze the response.

3. TEST

Test the suggested code in the browser.

4. VERIFY

Compare the result with reliable documentation and course material.

5. EXPLAIN

Explain what the code does in your own words.

05 — ASSESSMENT

Assessment Philosophy

Assessment should focus on both technical skills and the student's ability to understand and evaluate solutions.

Knowledge

Can the student explain the HTML or CSS concept?

Application

Can the student implement the concept in a working webpage?

Evaluation

Can the student identify problems in AI-generated code?

Explanation

Can the student explain why the solution works?

07 — INSTRUCTOR CHECKLIST

Before Publishing the Course

  • Define which AI tools students may use.
  • Provide examples of effective and ineffective prompts.
  • Explain how students should verify AI-generated information and code.
  • Clearly identify activities where AI use is expected.
  • Clearly identify assessments where independent work is required, if applicable.
  • Add the final AI-use policy to the Canvas syllabus.
  • Provide students with a consistent method for documenting meaningful AI assistance.
