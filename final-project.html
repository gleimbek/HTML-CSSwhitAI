CAPSTONE PROJECT

Final Project

Design, build, and document a complete, multi-page website that demonstrates everything learned across the course — structured HTML, styled and responsive CSS, accessible markup, and evidence of thoughtful, verified AI-assisted development.

01 — OVERVIEW

What the Final Project Is

The final project is the culminating assessment of the course. Students design and build an original, multi-page website from scratch, applying the HTML structure, CSS styling and layout, responsive design, and accessibility practices covered in every module. Students also document how they used AI throughout the process — what they asked, what they verified, and what they changed or rejected.

Why AI Documentation Matters

This project does not evaluate whether a student used AI. It evaluates whether the student can explain, verify, and take ownership of every line of code in their website — whether it was typed by hand or suggested by an AI tool.

02 — PROJECT REQUIREMENTS

What the Website Must Include

The final website must be built entirely with HTML and CSS covered in the course. It should consist of at least three connected pages sharing consistent navigation and styling.

STRUCTURE

Semantic HTML

Proper document structure using semantic elements such as header, nav, main, section, and footer.

STYLING

External CSS

A consistent visual system built with an external stylesheet — typography, color, spacing, and layout.

LAYOUT

Responsive Design

The site must adapt cleanly to mobile, tablet, and desktop screen sizes.

CONTENT

Navigation & Media

Working internal links, at least one list or table, and appropriately used images.

ACCESSIBILITY

Accessible Markup

Descriptive alt text, logical heading order, and sufficient color contrast.

PROCESS

AI Usage Log

A short written log describing AI prompts used, what was verified, and what was changed.

03 — PROJECT TIMELINE

Milestones

The project is developed gradually over the final weeks of the course rather than completed in a single submission, so students can receive feedback before the final deadline.

WEEK 14

Planning & Wireframe

Define the site's purpose, page map, and a simple wireframe or sketch of each page's layout.

WEEK 15

Build & Review

Build the HTML structure and CSS styling for all pages. Submit a draft for instructor and peer feedback.

WEEK 16

Final Submission

Refine the site based on feedback, complete the AI usage log, and submit the finished website.

04 — GRADING RUBRIC

How the Project Is Evaluated

The final project is worth 20% of the course grade, as defined in the syllabus. It is evaluated across five criteria:

Criterion What Is Assessed Points
HTML Structure Valid, semantic, well-organized markup 25
CSS & Layout Consistent styling and responsive layout 25
Accessibility Alt text, contrast, heading structure 15
Content & Navigation Working links, complete multi-page site 15
AI Usage Log Clear evidence of asking, verifying, and understanding 20
05 — AI USE ON THIS PROJECT

Ask. Verify. Understand.

Students may use AI tools throughout the final project the same way they used them in every module — to explain concepts, suggest approaches, and help debug problems. Every AI-assisted section of the website must be something the student can explain in their own words during review.

1. ASK

Ask AI a focused question about structure or styling.

2. EXAMINE

Read the explanation and generated code carefully.

3. TEST

Test the code in the browser and check the result.

4. VERIFY

Confirm correctness against course material or documentation.

06 — SUBMISSION

What to Submit

  • The complete website folder, including all HTML, CSS, and image files.
  • A working index page linking to every other page in the site.
  • The AI usage log as a separate document or page within the site.
  • Confirmation that the site has been tested in a browser at mobile, tablet, and desktop widths.
Questions About Scope

Students unsure whether a feature fits within course material should ask the instructor before the build milestone in Week 15.
