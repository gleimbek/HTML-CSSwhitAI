LEARNING OUTCOMES

What students will learn

The course develops practical skills for creating structured, styled, accessible, responsive, and standards-compliant websites.

01

Build HTML Documents

Create HTML documents using a text editor and understand how webpages are structured and rendered.

02

Structure Web Content

Work with links, lists, tables, images, multimedia, and forms.

03

Style with CSS

Use embedded and external CSS to control the appearance and layout of webpages.

04

Accessibility

Apply accessibility best practices to webpage structure and styling.

05

Validate & Improve

Use validation, formatting, and development tools to evaluate webpage quality.

06

Build a Website

Construct and publish a multi-page website that demonstrates the skills developed throughout the course.
